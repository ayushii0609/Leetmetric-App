# 🚀 LeetMetric App

A simple and responsive web application to track and visualize LeetCode user statistics.

## 📌 Features
- 🔍 Search any LeetCode username
- 📊 Display user stats (problems solved, ranking, etc.)
- 🎯 Clean and responsive UI
- ⚡ Fast and lightweight

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
